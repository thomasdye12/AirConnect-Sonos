64-character descriptor
Serializer 0x1070a68c and parser 0x1070a818 (wrapper 0x1070aa1c) establish:
- Prefix: two hex digits and a colon; flags range 0..3.
- Flag bit 0: append u32, u32, u64, each hexadecimal and colon-terminated.
  Format at 0x10c761ac is %08X:%08X:%016llX: (35 characters).
- Flag bit 1: append eight hex bytes, colon, u16, colon, u16 (26 characters).
  Format at 0x10c761c0 is %02X%02X%02X%02X%02X%02X%02X%02X:%04X:%04X.
- Both flags produce exactly 64 characters including the three-character prefix.
  Shorter forms are space-padded by the outer serializer at 0x102f0ad4..0x102f0af4.
The parser checks flag range and block conversion counts. This is a structured
descriptor, not a plain sender-IP/port string. Its fields' audio semantics have
not been established. The offline decoder intentionally accepts only canonical
fixed-width forms; it does not reproduce every permissive scanf input.

Activation consequences
BecomeGroupCoordinatorAndSource calls the source-state parser at 0x102bcc78.
An important distinction: parser failure does NOT immediately reject the action.
The branch at 0x102bd184 records that source state will not be restored, sets
r19=0, and returns to the remaining handoff logic at 0x102bcc84. The diagnostic
string is at 0x10c0db2c. Therefore an HTTP 200 from this action would not establish
that a fabricated or incomplete source state was accepted or restored.

The handler writes transport-mode field object+0x4244 = 2 at
0x102bce64..0x102bce68, whereas plain BecomeGroupCoordinator writes 1.
Neither is the member value 0 required by ordinary ChangeTransportSettings.
Its source-state field +0x138 controls additional branches: value 5 reaches
checks of descriptor field +0x120 for 7 or 16 at 0x102bcff8..0x102bd010.
The associated log refers to stopping a sink for adaptive-bitrate delegation.
These enum meanings are not fully resolved; do not substitute guessed values.
The alternate method thus transfers an existing source context. Replacing its
state with zeros or an endpoint string is not an established activation route.
